Токен в .env и бот-шутник

Цель — безопасное хранение токена в файле .env и бот-шутник, который отвечает случайной шуткой.

  1. 1Установить python-dotenv
  2. 2Создать .env и перенести токен
  3. 3Изменить начало bot.py
  4. 4Запустить и проверить
  5. 5Бот-шутник
  6. 6Свои шутки
Работаем с эхо-ботом, который уже есть в проекте my_bot. В каждом шаге показано, что было и что должно стать в файле. Код можно скопировать кнопкой «Скопировать» и вставить в PyCharm.
Номер задания совпадает с номером шага на экране. Сделал — отметь «Готово».
Как работать в PyCharm
  1. Проект. Открой проект my_bot с эхо-ботом: File → Open. Интерпретатор — Python 3.12.
  2. Терминал. Внизу открой Terminal (Alt+F12) — там выполняем pip install.
  3. Файлы. Правый клик по папке проекта → New → File (для .env и .gitignore).
  4. Код с сайта. «Скопировать» → в PyCharm Ctrl+V. Отступы внутри функций — 4 пробела, PyCharm ставит их сам.
  5. Запуск. Правый клик по bot.py → Run 'bot' (Ctrl+Shift+F10). Дальше — зелёный треугольник вверху.
  6. Перезапуск после правок. Кнопка Rerun (Ctrl+F5): старая копия остановится, новая запустится. Остановить — красный квадрат (Ctrl+F2).

Если что-то пошло не так

Что видимЧто сделать
No module named 'dotenv'В терминале PyCharm: pip install python-dotenv
Нет BOT_TOKEN: проверь файл .envФайл .env лежит в папке my_bot рядом с bot.py, называется ровно .env, внутри BOT_TOKEN=… без кавычек и пробелов
InvalidTokenТокен скопирован не полностью или с лишним символом. Скопируй заново из @BotFather

Conflict: terminated by other getUpdatesБот запущен дважды. Останови лишние запуски красным квадратом и перезапускай через Rerun
