Как работать в PyCharm
  1. Проект. Открой проект с эхо-ботом или создай новый: File → New Project, интерпретатор — Python 3.12 (Project venv).
  2. Библиотеки. Внизу открой Terminal (Alt+F12) и выполни pip install python-telegram-bot python-dotenv.
  3. Файлы. Правый клик по папке проекта → New → File (для .env и .gitignore) или New → Python File (для bot.py).
  4. Код с сайта. «Скопировать» → в PyCharm Ctrl+V. Отступы внутри функций — 4 пробела, PyCharm ставит их сам.
  5. Запуск. Правый клик по bot.py → Run 'bot' (Ctrl+Shift+F10). Дальше — зелёный треугольник вверху.
  6. Перезапуск после правок. Кнопка Rerun (Ctrl+F5): старая копия остановится, новая запустится. Остановить — красный квадрат (Ctrl+F2).

Если что-то пошло не так

Что видимЧто сделать
No module named 'dotenv' / 'telegram'В терминале PyCharm: pip install python-telegram-bot python-dotenv
Нет BOT_TOKENФайл .env лежит рядом с bot.py, называется ровно .env, внутри BOT_TOKEN=… без кавычек и пробелов
InvalidTokenТокен скопирован не полностью или с лишним символом. Скопируй заново из @BotFather
Conflict: terminated by other getUpdatesБот запущен дважды. Останови лишние запуски красным квадратом и перезапускай через Rerun
Бот повторяет /joke вместо шуткиВ фильтре эха нет ~filters.COMMAND или эхо стоит выше команд
NameError: name 'CommandHandler' / 'random' is not definedНе дописан импорт в начале файла
IndentationErrorВнутри функции отступ ровно 4 пробела. Выдели код и нажми Ctrl+Alt+L
Изменения не работаютФайл сохранён, но бот не перезапущен: нажми Rerun (Ctrl+F5)
